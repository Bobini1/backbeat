# Backbeat "Virtual Folders" App

This is experimental 70% vibe coded shit. It uses `backbeat_sdk` and FUSE/WinFSP to present your store
as a perfectly valid stepmania `Songs/` dir, or other stuff for other games.

It's fun, it's a novelty, and if you want some details backbeat _was_ originally this. This was my plan for integrating with other games before I came up with the library idea :P.
