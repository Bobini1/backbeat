# Backbeat Core

Backbeat is a standard for sharing and storing rhythm game charts in an efficient, easy, distributed manner.

This crate contains the core types, structs and functions for backbeat. These are the absolute essentials needed to do anything.

[Documentation](https://docs.rs/backbeat_core)

[More info](https://backbeat.ac/docs)

## Usage

```sh
cargo add backbeat_core
```

For a C implementation of the core structs, see `backbeat_c_sdk`.
